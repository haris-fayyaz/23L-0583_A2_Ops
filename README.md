# VisionGuard (23L-0583_A2_Ops)

![CI](https://github.com/haris-fayyaz/23L-0583_A2_Ops/actions/workflows/ci.yml/badge.svg)

Flask web app that tells if an uploaded image is AI-generated or real.
Run it with Docker Compose: copy `.env.example` to `.env`, fill the values, then `docker compose up -d`.
